# Evidence Workspace

This directory stores public evidence records, source inventories, review notes, and gap/conflict tracking used to build approved knowledge.

## What belongs here
- metadata and original summaries of guidelines, reviews, and studies;
- scope/population notes;
- limitations and applicability notes;
- formal certainty ratings when they exist or are explicitly assessed with a documented method;
- review status and verification dates;
- evidence-gap and contradiction records.

## What does not belong here
- copied full-text papers without redistribution rights;
- fabricated or model-invented citations;
- raw patient submissions;
- treatment conclusions based only on community anecdotes.

## Evidence workflow
`discover -> verify existence/source -> extract -> record scope/limitations -> assess/reuse formal certainty appropriately -> compare existing knowledge -> human review -> approve -> synthesize into knowledge/`

Use `schemas/evidence-record.schema.json` when creating structured evidence records.
