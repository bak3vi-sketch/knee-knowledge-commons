# Licensing Policy (Foundation Phase)

Knee Knowledge Commons intends to maximize responsible reuse while preserving attribution, provenance, and third-party rights.

Until formal legal review is completed:

- Original documentation and knowledge content contributed to this repository are intended for release under **Creative Commons Attribution 4.0 International (CC BY 4.0)**.
- Original software code added later should use a permissive open-source software license chosen and recorded before production code is broadly accepted.
- Third-party papers, guideline text, figures, tables, images, questionnaires, datasets, and other materials retain their original copyrights/licenses and must not be copied into this repository merely because they are cited.

Contributors should write original summaries and link/cite source material instead of reproducing copyrighted source text.

Before broad external contribution or software distribution, maintainers should complete legal review, add full SPDX-compatible license files, and clarify contributor terms. This document is an interim project policy, not legal advice.
