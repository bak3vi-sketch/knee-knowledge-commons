# Approved Knowledge

This directory is for reviewed public knowledge intended to become the canonical source for website content and source-grounded patient Q&A.

## Status rule
A file existing here does **not** automatically mean every statement is medically approved. Content pages must expose review status/metadata, and foundation placeholders must not be indexed as medical guidance.

## Initial scope
- `acl/`
- `meniscus/`

Expansion to PCL, MCL/LCL, patellofemoral injury, cartilage, multiligament injury, osteoarthritis, and other topics should follow only after the evidence/content workflow is proven.

## Page design
Follow `docs/CONTENT_MODEL.md` and `docs/EVIDENCE_MODEL.md`.

## Source rule
Do not paste large sections of source publications. Write original summaries, preserve provenance, and respect third-party copyright/licensing.
