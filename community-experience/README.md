# Community Experience

Lived experience is a core asset of Knee Knowledge Commons, but it must be handled differently from clinical evidence.

## Purpose
Community experience can reveal:
- what people wish they had known earlier;
- recurring communication failures;
- practical barriers to rehabilitation;
- fears, expectations, and decision confusion;
- questions that helped people prepare for care;
- recurring unmet needs that may deserve research.

## Boundary
Community experience does **not** by itself establish treatment effectiveness, safety, causality, or a universal rehabilitation rule.

## Storage model
Raw/private patient submissions should live in the future protected application database, not GitHub. This directory is for:
- methods and schemas;
- reviewed aggregate findings;
- intentionally public, governance-approved summaries with privacy safeguards.

## Publication rule
A community-derived statement should identify that it is self-reported/observational community information, describe the underlying sample and collection method when available, avoid causal language, and note selection/reporting bias where relevant.

## Current status
No patient stories should be collected through public GitHub during Foundation v0.1. Build the privacy/consent workflow first.
